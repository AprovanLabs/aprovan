# Brief: Fix the vcs-interface resolution-order collision

## Mission

Two unrelated products share the `vcs` interface id: the native workspace
commit store, and third-party git-hosting for PR review. Today the native,
credential-less compat entry wins zero-config resolution unconditionally in
the generic interface-catalog path, making the third-party git-hosting path
permanently unreachable. Fix the resolution order in `interfaces.ts` so both
remain reachable through their respective paths, without touching the
already-correct native short-circuit in `routes/tools.ts`.
